# WORKFLOW.md

Startup sequence (every session):

1. Read AGENTS.md
2. Read SOUL.md
3. Read USER.md
4. Read today's memory: memory/YYYY-MM-DD.md
5. Read yesterday's memory if exists
6. If main private session → read MEMORY.md
7. Resume task

After context compaction:

1. Re-read WORKFLOW.md
2. Re-read SOUL.md
3. Re-read USER.md
4. Re-read AGENTS.md
5. Resume task

Purpose:
Ensure consistent context restoration after compaction.
